Is there a firstmate-like tool that's less raw, cheaper on tokens, and more deterministic?

You liked firstmate's "one captain, a crew of agents" model but not its rawness, token burn, or LLM-for-everything plumbing. Researched what else exists in this category with real non-creator usage.

No clean swap exists yet

Nothing found combines firstmate's multi-agent crew orchestration with confirmed better determinism or token efficiency. Two tools (Claude Squad, Vibe Kanban) share firstmate's architecture but weren't shown to be more deterministic. One tool (Pi) solves the token problem but drops the crew model entirely. This looks like a gap in the ecosystem, not a firstmate-specific defect.

Firstmate, for reference

A single "first mate" agent spawns a crew of autonomous coding agents into isolated sessions (tmux/herdr/zellij/cmux/Orca), each with its own git worktree, and supervises them to PRs/merges/reports. It already has some deterministic plumbing — worktree creation, on-disk state, session persistence, and a bash fm-watch.sh watcher that sleeps on the fleet and only wakes the LLM when something's actionable (the "zero-token supervision" claim). But routing, code changes, report generation, and supervision judgment all still run through the LLM — consistent with feeling raw and token-hungry despite that marketing.

The options

Claude Squad

Closest architectural peer

Terminal app managing multiple Claude Code, Codex, Gemini, and Aider instances at once — each in its own tmux session and git worktree.

Advantages
  • Same tmux + worktree isolation model you liked in firstmate
  • Works across multiple underlying agent CLIs, not locked to one
Disadvantages
  • Claim that it cleanly delegates session/branch/git ops to non-LLM code — refuted 0-3
  • No evidence it's more token-efficient than firstmate
  • No install/star counts survived verification
github.com/smtg-ai/claude-squad

Vibe Kanban

Widest backend support

Kanban-board orchestration layer (BloopAI) running 10+ existing coding agents — Claude Code, Codex, Gemini CLI, Copilot, Amp, Cursor, OpenCode, Droid, CCR, Qwen — each in isolated worktrees/branches.

Advantages
  • Broadest agent-backend list of anything found
  • Visual kanban board vs. firstmate's chat-driven captain interface — more structured task review
Disadvantages
  • No confirmed edge on determinism or token cost over firstmate
  • Maintenance status post-BloopAI-shutdown is genuinely ambiguous (the "it's dead" claim was refuted, but that's not confirmation it's alive — check recent commits before adopting)
github.com/BloopAI/vibe-kanban

Cline

Most-adopted, but different category

VS Code extension, single-agent, plan/act workflow loop with terminal + browser control. Not a crew orchestrator at all.

Advantages
  • Strongest adoption evidence in this research: ~4.8-5M installs, independently verified on the VS Code Marketplace
  • Mature, well-trodden, easy to try
Disadvantages
  • No multi-agent crew — loses the thing you liked about firstmate
  • Claim that plan/act gives "more deterministic phase separation" — refuted 0-3
VS Code Marketplace listing

Pi

Best answer to the token complaint

By Armin Ronacher & Mario Zechner. Minimal core: four tools (Read, Write, Edit, Bash), no MCP. Lazy-loading skill system keeps only skill descriptions in context; full instructions/schemas load only when a skill actually fires.

Advantages
  • Sub-1K-token system prompt vs. ~7-10K for Claude Code / Cline / OpenCode — directly attacks your token-bloat complaint
  • Deliberately minimal, opinionated design (vs. firstmate's "raw" feel)
Disadvantages
  • Single-agent, no fleet/crew/parallel-worker concept at all
  • Trades away the exact multi-agent feature you liked about firstmate

Worth checking before you act on this

  • Whether Claude Squad or Vibe Kanban have anything like firstmate's zero-token bash watcher, or whether they poll/re-invoke the LLM for status — i.e. do they share firstmate's core token-burn problem?
  • Actual GitHub star/fork/contributor counts for Claude Squad and Vibe Kanban, to gauge real adoption against firstmate's ~2.5k stars.
  • Whether Pi's lazy-skill-loading pattern could be retrofitted into firstmate itself — keeping the crew model, cutting the token overhead — rather than switching tools outright.
  • Whether Vibe Kanban is still actively maintained post-BloopAI-shutdown, and by whom.
